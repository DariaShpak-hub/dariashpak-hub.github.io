Modular content system for *Feminism Unraveled* — an educational Instagram account exploring feminist theory and history.

## Scope

- Carousel templates
- Visual hierarchy system
- Scalable publishing structure

## About the Project

Designed for clarity and consistency in mobile-first environments. The system allows complex academic content — waves of feminism, key concepts, book recommendations — to be published in a visually coherent, accessible format.

The design language uses clean typography, consistent colour coding by topic, and a structured grid to make educational content scroll-friendly and visually engaging without sacrificing depth.
