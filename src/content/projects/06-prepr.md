Web and interface design for Prepr — a conversion-centric CMS built for full-service web agencies.

## Scope

- Web design
- Interface design across product modules
- Marketing page layouts
- Component visual systems

## About the Project

Designed for clarity, intuitive navigation, and consistency across product modules. The interface needed to communicate technical capability while remaining accessible to agency clients unfamiliar with CMS infrastructure.

Visual hierarchy, consistent iconography, and structured content blocks were central to the design approach — ensuring users could move through complex functionality without friction.
